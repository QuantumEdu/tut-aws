# ☁️ tut-aws — AWS Reference Guide

[![GitHub Pages](https://img.shields.io/badge/GitHub_Pages-live-brightgreen)](https://quantumedu.github.io/tut-aws/aws-reference-guide.html)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

Guía de referencia de AWS en una sola página HTML autónoma, pensada como recurso de estudio para certificaciones y consulta rápida.

## 📦 Contenido

| Sección | Qué incluye |
|---|---|
| 🔧 **Herramientas** | ~230 herramientas AWS organizadas en **21 familias de servicio** (EC2, S3, VPC, IAM, Lambda, RDS, DynamoDB, Route 53, CloudFront…) con acordeones colapsables |
| ⚙️ **Operaciones** | 23 tarjetas de Cloud Operations: monitorización (CloudWatch, CloudTrail, X-Ray), gobernanza (Config, Organizations, Control Tower), automatización (SSM, EventBridge, Step Functions), red y costes |
| 📝 **Examen** | 80 preguntas tipo test estilo **Solutions Architect / SysOps / Developer Associate** con respuesta oculta y explicación |

Cada herramienta incluye: **descripción**, **caso de uso** y **comando CLI / ubicación en consola**.

### 🏷️ Badges de prioridad

- <span style="background:#1AAB4B;color:white;padding:0 4px;border-radius:3px;">⭐ CORE</span> — principio de Pareto: el 20% de herramientas que cubren el 80% de casos reales
- <span style="background:#FFD700;color:#232F3E;padding:0 4px;border-radius:3px;">📋 CERT</span> — preguntan sí o sí en los exámenes de certificación AWS
