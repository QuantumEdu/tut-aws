# tut-aws

Este repositorio reúne material de apoyo sobre AWS y una guía de referencia en formato HTML para consulta rápida. Su objetivo es facilitar el acceso al contenido tanto desde GitHub como desde una versión publicada en la web, ofreciendo distintas opciones para visualizar el archivo `aws-reference-guide.html` según la necesidad del usuario.

Aquí encontrarás instrucciones sencillas para abrir la guía mediante GitHub Pages, un servicio de preview online o descargando el archivo raw para verlo localmente. Esto hace que el repositorio sea útil tanto para consulta personal como para compartir documentación de forma práctica.

### Opción 1: GitHub Pages (la mejor)                                                                                                      
                                                                                                                                            
 Activas GitHub Pages en el repo y se sirve como web real:                                                                                  
                                                                                                                                            
 ```                                                                                                                                        
   Settings → Pages → Source: "Deploy from a branch" → main → Save                                                                          
 ```                                                                                                                                       
                                                                                                                                            
 La URL será:                                                                                                                               
                                                                                                                                            
 ```                                                                                                                                        
   https://quantumedu.github.io/tut-aws/aws-reference-guide.html                                                                            
 ```                                                                                                                                       
                                                                                                                                            
 ### Opción 2: Servicio de preview (sin configurar nada)                                                                                    
                                                                                                                                            
 Pegas esta URL en el navegador:                                                                                                            
                                                                                                                                            
 ```                                                                                                                                        
   https://htmlpreview.github.io/?https://github.com/QuantumEdu/tut-aws/blob/main/aws-reference-guide.html                                  
 ```                                                                                                                                       
                                                                                                                                            
 ### Opción 3: Raw + extensión                                                                                                              
                                                                                                                                            
 Descargas el archivo raw y lo abres localmente:                                                                                            
                                                                                                                                            
 ```                                                                                                                                        
   https://raw.githubusercontent.com/QuantumEdu/tut-aws/main/aws-reference-guide.html                                                       
 ```                                                                                                                                       
                                                                                                                                            
 (El navegador descargará el archivo; lo abres con doble clic)
