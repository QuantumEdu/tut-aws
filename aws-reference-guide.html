🔧 Herramientas ⚙️ Operaciones 📝 Examen (80 Q)

1. Herramientas AWS organizadas por familia de servicio

Cada servicio principal de AWS se muestra como un acordeón desplegable con sus componentes internos, recursos asociados, CLI y ubicación en consola. Estas son las herramientas que aparecen en las certificaciones Solutions Architect Associate, SysOps Administrator y Developer Associate.

2. Configuraciones y Herramientas de Operaciones AWS

AWS Operations abarca los servicios para gestionar, monitorizar, automatizar y asegurar entornos a escala. A continuación, las herramientas clave agrupadas por dominio operacional.
